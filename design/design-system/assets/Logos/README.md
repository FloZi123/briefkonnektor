# Logos

Einfarbige Marken: `ink` (#16203A) und `flink` (#2F5BEA) auf hellem Grund; Weiß und Flink-Hell (#8FA8FF) auf `ink`. Die Tile-Variante ist Weiß auf `flink`.

- Lockup (Zeichen + Wortmarke): Standard für Website-Header, E-Mail-Kopf, Rechnungen.
- Mark: Avatar, Favicon ab 32 px, Platz mit wenig Breite.
- Favicon: ohne Tempo-Linien, für 16–32 px.
- Tile: App-Icon, Social-Profile.

Mindesthöhe Zeichen 24 px, Wortmarke 20 px. Schutzraum = Kuverthöhe. Nicht drehen, nicht neu setzen.
