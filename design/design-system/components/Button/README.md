# Button

Primär für die eine Hauptaktion je Ansicht, Sekundär für Alternativen, Link für Ausstiege. Mindestens 48 px hoch, auf dem Handy volle Breite. Beschriftung sagt, was passiert („Bescheid fotografieren“), nie „OK“ oder „Weiter“ allein. Ladezustand: Beschriftung wechselt („Wird gesendet …“), Button bleibt sichtbar.
