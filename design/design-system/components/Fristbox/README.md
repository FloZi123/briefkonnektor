# Fristbox

Zeigt die aus dem Bescheid abgeleitete Frist. Steht über dem Formular, nie darunter. Nennt immer beides: Fristregel („1 Monat“) und konkretes Datum. Farbe `frist` (orange), nicht `fehler` – eine Frist ist Handlungsbedarf, kein Fehler. Das Datum ist eine Wiedergabe aus dem Bescheid, keine Rechtsauskunft; der Hinweis „laut Bescheid“ bleibt.
