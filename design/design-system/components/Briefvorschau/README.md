# Briefvorschau

A4-Miniatur des gerenderten Briefs: Absender, Rücksendeangabe, Empfänger, Aktenzeichen in `mono`, Betreff fett, Textzeilen als Platzhalter oder echte erste Zeilen. Einziges Element mit `shadow-card`, damit es wie ein Blatt auf dem Tisch liegt. Daneben der Schrittzähler und die Handlungsaufforderung.
